## 🚀 Overview

This repository contains the source code for my interactive developer portfolio. It is designed to be highly dynamic, responsive, and visually appealing, reflecting modern UI/UX principles while serving as a central hub for my professional projects, skills, and resume.

Beyond just a static site, this portfolio integrates **Google Gemini API** for intelligent capabilities and utilizes **Firebase** for backend services.

## ✨ Features

- **Modern UI:** Built with React 19 and styled flawlessly using Tailwind CSS.
- **Smooth Animations:** Powered by Framer Motion to create engaging, fluid user experiences.
- **AI Integration:** Implements `@google/genai` to bring intelligent, dynamic capabilities to the portfolio.
- **GitHub Calendar:** Integrated `react-github-calendar` to showcase my live open-source contribution graph.
- **Serverless Backend:** Configured with Firebase for real-time interactions and fast data delivery.
- **Optimized Build:** Vite ensures lightning-fast HMR during development and heavily optimized production builds.

---

## 🛠️ Tech Stack

*   **Frontend Framework:** React 19
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS, `clsx`, `tailwind-merge`
*   **Animations:** Framer Motion (`motion`)
*   **Icons:** Lucide React
*   **Backend & Hosting:** Firebase
*   **AI Models:** Google Gemini (`@google/genai`)

## 🚀 Running Locally

To get a local copy up and running, follow these simple steps:

### Prerequisites
Make sure you have Node.js and npm (or pnpm/yarn) installed.

### Installation

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/rakesh2971/personal-portfolio.git
    cd personal-portfolio
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Setup Environment Variables:**
    Copy `.env.example` to `.env` and configure your Firebase and Gemini credentials.
    ```bash
    cp .env.example .env
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```

Open `http://localhost:3000` in your browser to view the portfolio.
